# Prompts reutilizables

## Mejorar un proyecto existente
Usa VINK Web Interactiva para mejorar esta página. Revisa primero el código y sus
recursos; elige el perfil y una firma de movimiento que encajen con la marca.
Implementa una apertura cuidada, scroll con intención y una interacción útil.
Conserva identidad, textos aprobados y funciones. Entrega el código integrado,
verifica móvil y movimiento reducido y resume lo que comprobaste. No te quedes en
una propuesta ni instales bibliotecas que no hagan falta.

## Aplicar a varias webs
Usa VINK Web Interactiva en los proyectos adjuntos. Identifica cada sitio y sus
recursos, elige un perfil propio para cada uno y mejora su movimiento e interacción.
Conserva cada identidad y sus dependencias. Entrega un resultado revisable por
proyecto y una lista breve de lo completado y lo pendiente. No traslades precios,
teléfonos, imágenes o testimonios de una marca a otra.

## Partir de una referencia
Usa VINK Web Interactiva. Analiza la referencia adjunta y describe únicamente los
comportamientos que puedas observar. Diseña una experiencia propia para mi marca,
con una apertura y un ritmo de scroll de ambición similar. Cambia la composición
y el lenguaje visual según mi contenido. Implementa el resultado con los recursos
disponibles y señala cualquier modelo o medio que falte.

## Añadir un recurso 3D
Usa VINK Web Interactiva para integrar el modelo o escena adjunto. Diseña una sola
interacción relevante y conserva el producto exactamente. Incluye poster estático,
carga según necesidad y una versión móvil ligera. Si el archivo no es un modelo
3D, explica qué animación permite e implementa la alternativa disponible.

## Iterar una página que ya tiene movimiento
Usa VINK Web Interactiva para revisar el movimiento existente. Conserva lo que
ayude a recorrer y entender la página, corrige conflictos y elige una firma clara.
Prioriza lectura, respuesta de controles y fluidez en celular. Implementa y verifica
los cambios; informa si alguna comprobación no pudo ejecutarse.
